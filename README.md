# dam-gestion

Actividad Individual 1 de Desarrollo de Interfaces (DAM). Proyecto en proceso.

## Entrega actual

- [Proyecto completo en ZIP](dam-gestion.zip): código fuente, configuración y dependencias declaradas, conservando las carpetas del proyecto.
- [Memoria de prácticas en PDF](Memoria_Actividad_Individual_1_v04.pdf): primera evidencia, con el formato de Nebrija y sin conclusiones finales.

## Ejecutar

Descarga y extrae el ZIP. Con Node.js, npm e Ionic CLI instalados, abre la carpeta extraída y ejecuta:

```sh
npm ci
ionic serve
```

La aplicación estará disponible en http://localhost:8100.

El ZIP no incluye node_modules ni cachés; npm ci instala las dependencias.
