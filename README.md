# dam-gestion

Actividad Individual 1 de Desarrollo de Interfaces (DAM). Proyecto Ionic en proceso.

El ZIP contiene el código fuente y la configuración del proyecto, sin memoria PDF.

## Ejecutar

Extrae el ZIP y, con Node.js, npm e Ionic CLI instalados, ejecuta:

```sh
npm ci
ionic serve
```

Aplicación local: http://localhost:8100.

No se incluyen node_modules ni cachés.
